# Project1
 Create a prefix-expression notation calculator that prompts the user for an expression in prefix notation and calculates the result of the expression

Using the '$' character will pull a number from the history based on its index. For example '$2' will give you the second result you have gotten from your input. Inputting a history index that has not happened yet is not allowed and the program will start over from the beginning if attempted.

All errors, such as inputting a character that isn't a number, '$', or operator, dividing by 0, or inputting an expression that is not in prefix notation for a number of reasons will result in an output of a description of the error and let you input another expression.
